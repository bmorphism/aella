# Aellith Conlang

Minimal conlang built from the Aella jealousy primitives.

Primitives:
- en = envy
- in = insecurity
- po = possessiveness
- th = threat detection
- co = compersion

Roles:
- -a experiencer
- -b rival
- -c bond

Modifiers:
- intensity: ka (mild), ke (moderate), ku (severe)
- evidential: he (hedged), na (negated)

Examples:
- en mia-a rau-b ke
- in mia-a lin-c he
- po mia-a rau-b lin-c
- th mia-a rau-b lin-c ku
- co mia-a lin-c ka

Parsers:
- Rascal: rascal/Aellith.rsc
- ANTLR4: antlr/Aellith.g4

See: aellith-quantum.md for the Solomonoff/quantum-optimized phonetic design.

Parity markers: p0/p1/p2 (optional checksum).

Scope markers: sA/sB/sC (perspectival), sX (unspecified).
Phase markers: pm (macro), pc (compile), pr (runtime).
